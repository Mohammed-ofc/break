# 💖 Break Time Tracker (1-Hour Break Calculator)

A lightweight, beautiful, and intuitive 1-hour break calculator & time tracker web app designed with a delightful girly aesthetic (soft pastel pinks, rose gold, glassmorphism cards, and uplifting daily affirmations).

![Break Time Tracker](https://img.shields.io/badge/Status-Active-ff6584)
![License](https://img.shields.io/badge/License-MIT-e8839b)

## 🌸 Key Features

- **Red "Enjoy" ➔ Green "Started" Toggle**: Single-button control to start/stop break tracking easily.
- **Auto-Reset on 1-Hour Completion**: Automatically logs completed breaks and resets the timer back to 60:00 for the next break.
- **Multi-Day Log Table**: Keeps permanent daily log history with Date, Start Time, Duration, and Badges (`✅ 1hr Done` / `⏱️ Paused`).
- **Daily Affirmations Banner**: Motivational & uplifting quotes with a quick **"💌 New Affirmation"** refresher.
- **Hearts & Sparkles Confetti Burst**: Magical particle animations whenever breaks start or complete.
- **Flawless Mobile Responsive UI**: Optimized for mobile viewports, iPhones, Android devices, and web preview platforms like Netlify.
- **100% Lightweight**: Built with pure HTML5, CSS3, and JavaScript (zero external framework dependencies).

## 🚀 Quick Start

Simply open `index.html` in any modern web browser or host on Netlify / Vercel / GitHub Pages!

```bash
# Clone the repository
git clone https://github.com/Mohammed-ofc/break-time-tracker.git

# Navigate into project directory
cd break-time-tracker

# Open in browser
open index.html
```
